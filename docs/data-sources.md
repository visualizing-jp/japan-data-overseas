# データソース

正本。パースや指標の定義はここを先に直す。

## 調査

- 外務省「海外在留邦人数調査統計」（e-Stat 統計コード `00300100`）
- 公表ページ: https://www.mofa.go.jp/mofaj/toko/tokei/hojin/index.html
- 各年 10月1日現在。在外公館に出された在留届をもとにした推計
- 取得: e-Stat ファイル配信（`scripts/catalog.json` の年 → `statInfId`）。`npm run fetch` が `data/raw/{年}.xlsx` に落とす

## 区分

| 区分 | 2023年版までの説明 | 2024年版からの説明 |
| --- | --- | --- |
| 長期滞在者 | 3か月以上の在留者のうち、いずれ日本に戻るつもりの人 | 在留国に期限を定めて居住している人 |
| 永住者 | 在留国から永住権を認められ、生活の拠点を海外へ移した人 | 在留国に期限を定めずに居住している人 |

2024年版の言い換えで数の段差は見られない。ただし同じ区分の連続とは言い切れないので、長期・永住とその割合の線は2024年から破線にし、年に印（MARKS）を付けた。総数は区分によらないので実線のまま。

## 年ごとの形式

| 年 | 形式 | 取れるもの |
| --- | --- | --- |
| 2014・2015・2017 | 統計表 4.1（全体・地域）と 4.2（国・公館） | 総数・長期・永住、男女、本人／同居家族、職業6区分、年齢6区分 |
| 2016 | 1枚の横長表（年度ごとの列） | 国別の総数・長期・永住（H28 列） |
| 2018・2019・2025 | 「一覧表」シート（A 列 地域、B 列 国） | 国別の総数・長期・永住 |
| 2020〜2024 | 機械判別用の一覧（見出し1行） | 国別の総数・長期・永住 |

最新年版の「邦人数推移」シートから 1991年以降の総数・長期・永住 × 男女、「都市別邦人数上位50位」から直近5年の都市順位を取る。

職業・男女・年齢の国別内訳は **2017年が最後**。仕事ビューはこの年の断面に固定する。

## 名寄せ

- 国名は NFKC でそろえ、括弧だけ全角に戻し、注記（※…）を落とす
- 表記ゆれは `src/lib/labels.ts` の `COUNTRY_ALIASES` で最新年の表記へ寄せる
- `npm run data` が「最新年に無い国」を一覧する。現時点の残りは実際に無くなった・公表されなくなったもの
  - アンティル諸島（蘭領）: 2010年に解体
  - マルティニーク（仏領）・セントマーティン（蘭領）・バージン諸島（英領）: 近年の一覧に無い
  - ウクライナ: 2023年以降、安全上の理由で公表を差し控え
- イラクは2025年だけ、アフガニスタン・シリアは2014年以降一度も一覧に出てこない（同じく非公表）
- 地域は最新年に近い年の所属を国に付ける。地域の値は国の合計、全世界は推移表の公表値

## 配信チャンク

| ファイル | 内容 |
| --- | --- |
| `era.json` | 在留区分 × 性 × 年（1991–） → pop |
| `geo.json` | 全世界・地域・国 × 在留区分 × 年（2014–） → pop、地域の所属、都市順位 |
| `detail.json` | 2017年の 地域・国 × 区分（総数・永住・長期・職業6） × 本人/家族 × 性、地域・国 × 年齢 × 性 |
| `meta.json` | 年一覧・出典 |

## 検証（`npm run verify`）

- 推移: 総数 = 長期 + 永住 = 男 + 女（全年）
- 2025年: 総数 1,298,170、地域の合計が一覧表の地域行と一致
- 各年: 国の合計 ≤ 全世界、差は 1% 未満（非公表国の分）
- 国・地域: 総数 = 長期 + 永住
- 2017年: 総数 = 長期 + 永住 = 男 + 女、長期 = 職業の合計、本人 + 家族 = 計、地域の合計 = 全世界、年齢の合計 = 全世界

## 範囲外

- 3か月未満の渡航（旅行・出張）。延べ回数の出国者数は姉妹サイト「日本人はどこへ出かけてきたか」
- 日本学生支援機構の留学状況調査（集め方も定義も違う）
